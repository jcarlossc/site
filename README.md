# DataQuantum — Portfólio Profissional

> **Transformando dados em decisões.**

Portfólio profissional da **DataQuantum — Soluções em Dados**, desenvolvido para apresentar projetos, serviços, tecnologias e soluções nas áreas de **Análise de Dados, Ciência de Dados, Engenharia de Dados e Business Intelligence**.

🌐 **Acesse o portfólio:**
https://jcarlossc.github.io/site/

---

## 📌 Sobre o projeto

O **DataQuantum Portfolio** é um site profissional desenvolvido para centralizar a apresentação de projetos e serviços relacionados ao ecossistema de dados.

A proposta central é:

> **Transformando dados em decisões.**

O portfólio apresenta o fluxo completo de trabalho com dados, desde a coleta e preparação até análise, modelagem, engenharia e entrega de soluções.

## 🎯 Objetivos

O projeto possui quatro objetivos principais:

* Apresentar a atuação profissional da DataQuantum.
* Demonstrar projetos práticos de dados.
* Centralizar tecnologias e competências técnicas.
* Facilitar o contato para novos projetos e oportunidades profissionais.

O site também funciona como uma **vitrine técnica**, permitindo visualizar exemplos de aplicações envolvendo Python, R, SQL, APIs, ETL, Machine Learning, BI e bancos de dados.

## 📊 Áreas de atuação

### 01 — Análise de Dados

Exploração, tratamento e análise de dados para identificação de padrões, tendências e indicadores.

**Principais atividades:**

* EDA — Exploratory Data Analysis
* Tratamento e preparação de dados
* KPIs
* Dashboards
* Relatórios
* Visualização de dados
* Análises estatísticas

### 02 — Ciência de Dados

Aplicação de estatística e Machine Learning para construção de modelos capazes de identificar padrões e realizar previsões.

**Principais atividades:**

* Machine Learning
* Modelagem estatística
* Modelos preditivos
* Classificação
* Regressão
* Análise de desempenho

### 03 — Engenharia de Dados

Construção de processos e pipelines responsáveis pela coleta, transformação, integração e disponibilização dos dados.

**Principais atividades:**

* ETL / ELT
* Data Pipelines
* APIs
* Integração de dados
* Bancos de dados
* Data Warehouse
* Automação de processos

### 04 — Business Intelligence

Transformação de dados em informações visualmente acessíveis para acompanhamento de indicadores e suporte à tomada de decisão.

**Principais atividades:**

* Indicadores
* Dashboards
* Visualização de dados
* BI
* Análise de desempenho
* Relatórios gerenciais

# 🔄 Processo de trabalho

O processo apresentado no portfólio segue uma abordagem orientada ao problema.

```text
┌──────────────┐
│  01 Entender │
└──────┬───────┘
       ↓
┌──────────────┐
│ 02 Preparar  │
└──────┬───────┘
       ↓
┌──────────────┐
│ 03 Analisar  │
└──────┬───────┘
       ↓
┌──────────────┐
│ 04 Entregar  │
└──────────────┘
```

### 01 — Entender

Compreensão do problema, contexto e objetivos do projeto.

### 02 — Preparar

Coleta, tratamento, limpeza, validação e organização dos dados.

### 03 — Analisar

Análise exploratória, estatística, modelagem e identificação de padrões.

### 04 — Entregar

Disponibilização da solução final para utilização e geração de valor.

# 🚀 Executando localmente

Clone o repositório:

```bash
git clone https://github.com/jcarlossc/site.git
```

Entre no diretório:

```bash
cd site
```

Como se trata de uma aplicação web estática, também é possível abrir o `index.html` diretamente no navegador.

Para utilizar um servidor local com Python:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
