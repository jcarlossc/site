📊 Análise e Previsão da População Brasileira

1. Introdução

Este notebook apresenta um fluxo completo de análise de dados da população brasileira utilizando dados disponibilizados pelo Instituto Brasileiro de Geografia e Estatística (IBGE).

O projeto tem como objetivo demonstrar, de forma reprodutível, as principais etapas de um processo de Data Science:

  • consumo de uma API pública;
  • extração de dados com `requests`;
  • transformação da resposta JSON;
  • construção de um DataFrame com `pandas`;
  • validação e tratamento dos dados;
  • análise exploratória;
  • preparação das variáveis;
  • separação entre treinamento e teste;
  • treinamento de um modelo de regressão polinomial de segundo grau com valores temporais aleatórios;
  • avaliação do modelo;
  • análise dos resíduos;
  • treinamento de um modelo de regressão polinomial de segundo grau com valores temporais não aleatórios;
  • comparação entre valores aleatórios e não aleatórios.

Objetivo

Investigar a relação entre o ano e a população brasileira e construir um modelo de regressão capaz de estimar a população a partir do ano.

Importante: a regressão utilizada neste notebook tem finalidade educacional e analítica. Ela não substitui projeções demográficas oficiais, que consideram variáveis demográficas muito mais complexas.

Tecnologias

  • Python
  • Requests
  • Pandas
  • Matplotlib
  • Scikit-learn

Fonte dos dados

Os dados são obtidos através de uma API pública disponibilizada pelo IBGE.

def limpar_serie(serie: list[dict[str, str | None]]) -> list[dict[str, int]]:
    """
    Remove períodos sem valor e converte os valores para inteiros.
    Args:
        serie: Lista de dicionários contendo ano/período e valor.
    Returns:
        Lista contendo somente anos com valores válidos.
    """
    resultado = []

    for item in serie:
        for ano, valor in item.items():
            if valor is not None and ano.isdigit():
                resultado.append(
                    {
                        "ano": int(ano),
                        "valor": int(valor),
                    }
                )

    return resultado

Os resultados obtidos indicam um desempenho elevado do modelo de regressão na estimativa da população. O **MAE (Mean Absolute Error)** foi de aproximadamente **160.778 habitantes**, indicando que, em média, as previsões diferiram dos valores reais em cerca de 161 mil habitantes. Considerando que a população analisada está na ordem de centenas de milhões de habitantes, esse erro representa uma pequena diferença relativa.

O **RMSE (Root Mean Squared Error)** foi de aproximadamente **186.591 habitantes**. Como o RMSE atribui maior peso aos erros mais elevados, seu valor superior ao MAE indica a existência de algumas previsões com erros relativamente maiores, embora ainda pequenos em relação à magnitude da variável analisada.

O modelo apresentou **R² de aproximadamente 0,9997 no conjunto de teste**, enquanto o R² no treinamento foi de aproximadamente **0,9997**. Esses valores indicam que o modelo consegue explicar praticamente toda a variação observada na população dentro dos dados analisados. A proximidade entre os valores de R² de treinamento e teste também não indica uma diferença relevante de desempenho entre os dois conjuntos, sugerindo boa consistência do ajuste para essa amostra.

A comparação entre os valores reais e previstos mostra erros individuais relativamente pequenos. O menor erro absoluto observado foi de aproximadamente **57.269 habitantes**, enquanto o maior foi de aproximadamente **314.618 habitantes**. Os erros percentuais variaram entre aproximadamente **0,03% e 0,15%**, demonstrando que, para todas as observações do conjunto de teste, as previsões ficaram muito próximas dos valores reais.

De forma geral, os resultados mostram que o modelo apresentou excelente ajuste aos dados utilizados na análise. Entretanto, o R² extremamente elevado deve ser interpretado com cautela, especialmente porque o conjunto de dados apresenta uma forte tendência temporal e poucas observações. Portanto, o elevado desempenho observado não deve ser utilizado isoladamente para afirmar que o modelo terá a mesma precisão em períodos futuros ou em dados fora do intervalo analisado.

✅ 10. Comparação final - Modelo com Divisão aleatória e não Aleatória

Comparação entre Regressão Polinomial com valores temporais aleatórios e não aleatórios, respectivamente.

A regressão polinomial apresentou excelente ajuste quando os dados foram divididos aleatoriamente, com R² de 0,9997 no conjunto de teste. Entretanto, essa abordagem não representa adequadamente um cenário de previsão temporal, pois permite que observações de anos posteriores participem do treinamento.

Na regressão polinomial com divisão não aleatória, utilizando 2000–2019 para treinamento e 2020–2023 para teste, o R² caiu para aproximadamente 0,52. Embora os erros percentuais tenham permanecido relativamente baixos, os resíduos apresentaram comportamento progressivamente negativo, indicando que o modelo passou a superestimar a população nos anos mais recentes.

Dessa forma, enquanto o modelo com divisão aleatória alcançou uma aproximação muito boa no que diz respeito aos números reais de habitantes para o ano de 2026; o modelo com divisão não aleatória fornece uma avaliação mais realista da capacidade de generalização do modelo, dada a divisão mais adequada para uma série temporal, mesmo não alcançando uma boa aproximação. A previsão de 2026 deve ser interpretada como uma estimativa experimental, e não como uma projeção demográfica oficial..
